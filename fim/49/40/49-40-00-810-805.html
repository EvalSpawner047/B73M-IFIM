Maintenance Message 49-41012 - Fault Isolation
NO APU ROTATION SHUTDOWN
Detected by: APU CONTROLLER
OMR 001-018
A.
Description
(1)
This task is for this maintenance message:
(a)
NO APU ROTATION SHUTDOWN DETECTED BY: APU CONTROLLER
(2)
The APU speed did not get to 7% in 20 seconds during an APU start cycle. The time of 20 seconds starts after the air inlet door has opened.
(3)
The APU FAULT light on the P5 forward overhead panel will show for this maintenance message.
(4)
Examine the fault history to see if 49‑41012 and 49‑41254 occurred at the same time. If the two maintenance messages occurred at the same time, try to start the APU again. The start duty cycle for the APU is three times in a 15 minute interval. If you do three successful or unsuccessful start cycles in a 15 minute interval, it is recommended that you wait 15 minutes after the third start cycle for the power electronics to cool (AMM TASK 49-11-00-860-801).
(5)
This maintenance message can show intermittently with maintenance message 49‑41254. These messages can show intermittently because of these conditions:
(a)
After a flight of 4 or more hours
(b)
High humidity (>60%)
(c)
Temperature ranges from 55 F (12.8 C) to 65 F (18.3 C)
B.
Initial Evaluation
(1)
Use one of these steps to supply power to the APU electronic unit:
(a)
Set the APU switch on the P5 panel to ON and then wait 30 seconds.
(b)
Set the APU MAINT POWER switch to TEST and then wait 30 seconds. This is the task:
  • APU BITE Procedure, AMM TASK 49-61-00-700-801.
(2)
Look for the maintenance message on the OMF, and then set the APU switch to OFF (or set the APU MAINT POWER switch to NORM).
(3)
If the OMF showed ACTIVE for the maintenance message with the switch set to ON (or TEST), then do the Fault Isolation Procedure below.
(4)
If the OMF showed NOT ACTIVE (or if the message did not show), then there was an intermittent fault.
C.
Fault Isolation Procedure
 DO NOT OPERATE THE APU START DUTY CYCLE MORE THAN 3 TIMES, FOLLOWED BY A 15 MINUTE COOL OFF PERIOD. WAIT 30 SECONDS BETWEEN STARTS. ONE START OF THE APU CAN CLEAR THE FAULT AS INTERMITTENT. IF YOU DO NOT OBEY THIS CAUTION, THE APU CAN SHOW A HIGH-TEMPERATURE FAULT. DAMAGE TO THE APU CAN OCCUR.
(1)
Do this task:
  • APU Starting and Operation, AMM TASK 49-11-00-860-801.
(a)
Set the APU switch to ON (or set the APU MAINT POWER switch to TEST) and then wait 30 seconds.
(b)
Look for the maintenance message on the OMF, and then set the APU switch to OFF (or set the APU MAINT POWER switch to NORM).
(c)
If the OMF showed NOT ACTIVE (or if the message did not show) with the switch set to ON (or TEST), then you corrected the fault.
(d)
If the OMF showed ACTIVE for the maintenance message, then continue.
