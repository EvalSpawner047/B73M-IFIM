Maintenance Message 71-43694 - Fault Isolation
ENGINE STALLED DURING START
Detected by: ENGINE-2 EEC CHANNEL-B
A.
Description
(1)
A stall has been detected during an start attempt. Start stall is detected as a function of 1) the ground or inflight start stall EGT limit and low core speed (N2) acceleration, 2) hung start (no N2 acceleration for 15 seconds) and 3) PS3 loss and subsequent engine hang (no N2 acceleration). Fault latched until the fuel switch is turned off or the EEC loses power.
(2)
Start stalls can be caused by loss of air pressure to the engine starts because of incorrect ECS valve configuration or insufficient airflow from the starting air source (APU, cross-bleed engine, or ground start cart). Monitor the ECS duct pressure on the overhead panel when you try to start the engine. The AMM recommends a minimum of 30 PSIG before you try to start the engine. During the start, do not change the ECS valve configuration until the engine has reached stable idle and the start EGT tic mark is no longer displayed on the EGT dial.
(a)
When using APU or Engine 1 as starting air source, if duct pressure is initially greater or equal to 30 PSIG and drops after the start valve opens, the bleed air isolation valve may be stuck in a partially open position.
(b)
If the bleed air isolation valve is stuck partially open or movement is sticky, cycling the ISOLATION VALVE switch on the P5-10 panel from CLOSED to OPEN a few times may free up the movement of a sticky valve.
(3)
Start stalls because the aircraft spar valve failed to close have a recognizable pattern of repeated failed start attempts. The first start attempt can reach about 50% N2 before a start stall (hung start) occurs. The second start attempt can reach about 40% N2. The third start attempt can cause a no light off or flameout just after light off. Position faults for fuel-driven actuators can be set because of insufficient fuel pressure.
(4)
The amount of fuel flow the EEC is able to provide to the combustor during start is limited by the sensed compressor discharge pressure (PS3). If the PS3 sensor is faulted, sensed pressure frozen due to contamination (frozen moisture, dirt, etc.), or PS3 rise limited by another hardware failure, the EEC may not be able to provide enough fuel flow to accelerate the engine to idle and this maintenance message may be set. Check for PS3 sensor and related system faults to see if the start stall may be caused by this issue.
(5)
Fuel nozzles with carbon buildup (coke) in the pilot primary orifice can also cause start stalls. Fuel nozzle coking can be monitored remotely with data from the ACMS Start snapshot. If you think fuel nozzle coking can be the cause of the start stall, look to see if there is a Fuel Nozzle CNR from CFM or if there is scheduled maintenance for replacing fuel nozzles because of coke buildup. Contact CFM if you need support in to finding out if fuel nozzle coking can be the cause of the start stall.
(6)
Start stalls can also occur because of insufficient fuel prefill of the pilot secondary (PSec) fuel manifold. Start stalls for this cause typically occur after fuel system maintenance or long periods between engine operation (ex. first start of the day) where air can be introduced into the fuel circuit because of component replacement or leaks in the fuel manifold circuit (ex. leaky fuel nozzle check valve). The start stall will usually occur after starter cutout (63% N2) but before getting to idle. Contact CFM if you need support to find out if insufficient PSec prefill can be the cause of the start stall.
(7)
A start stall is indicated to the flight deck by the EGT indication box on the forward flight display flashing white and the engine start automatically aborted by the EEC.
B.
Fault Isolation Procedure
(1)
This maintenance message can show when there is not a failure in the system.
(a)
Engine stall during an engine start can be caused by one of these conditions:
1)
Incorrect ECS system setting because of one or the two of these actions before the stable idle of the engine is reached:
a)
Air condition PACK switched on
b)
Isolation valve actuated
2)
Starting air source problem
3)
High tailwind
(b)
Look for flight crew reports for one of the conditions.
(c)
If the engine EGT start limit was not exceeded and you find a report of one of the conditions during an engine start, then no maintenance is necessary. The engine can be restarted.
(2)
For the bleed air isolation valve, V16, do this task:
  • Bleed Air Isolation Valve Operational Test, AMM TASK 36-13-00-710-801.
(a)
If the bleed air isolation valve does not operate as specified in the AMM task, then do these steps:
1)
Replace the bleed air isolation valve, V16. These are the tasks:
  • Bleed Air Isolation Valve Removal, AMM TASK 36-13-04-000-801,
  • Bleed Air Isolation Valve Installation, AMM TASK 36-13-04-400-801.
2)
Do this task for engine 2:
  • Test No. 32 - Engine Idle System Test, AMM TASK G71-00-00-700-808-G00.
3)
If the maintenance message does not show on the ground test display, then you corrected the fault.
(b)
If the bleed air isolation valve operates as specified in the AMM task, then continue.
