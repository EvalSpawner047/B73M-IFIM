Maintenance Message 27-51351 - Fault Isolation
TRAILING EDGE FLAP UNCOMMANDED MOTION (UCM)
Detected by: FLAP/SLAT ELECTRONICS UNIT (FSEU)
A.
Description
(1)
This task is for this maintenance message:
(a)
TRAILING EDGE FLAP UNCOMMANDED MOTION (UCM)
(2)
Uncommanded motion of the Trailing Edge Flap System was detected by the FSEU. The FSEU uses inputs from the Flap Lever Position Sensor, the Flap Position Sensors and the No. 1 and No. 8 Flap Skew Sensors to determine an uncommanded motion.
B.
Initial Evaluation
(1)
Arm the alternate control system to prevent trailing edge flap movement with hydraulic power.
(a)
Make sure that the position of the flap control lever agrees with the position of the flaps.
(b)
Make sure that the ALTERNATE FLAPS control switch is at the OFF position.
(c)
Set the ALTERNATE FLAPS ARM switch to the ARM position.
(d)
Supply hydraulic power to system B.
(e)
Open and then close these circuit breakers to reset the fault in the FSEU: C211, FLIGHT CONTROL FSEU DC 1 [P6-2, A8] and C1468, FLIGHT CONTROL FSEU DC 2 [P6-2, A9].
(2)
Look for trailing edge flap movement as you do the next step to disarm the alternate control system.
(a)
Set the ALTERNATE FLAPS ARM switch to the OFF position.
(b)
If the trailing edge flaps move when you disarm the alternate control system, then do these steps:
1)
Remove hydraulic power from system B.
2)
Do the Fault Isolation Procedure below.
(c)
If the trailing edge flaps do not move when you disarm the alternate control system, then continue.
(3)
Simulate an airspeed of more than 60 knots to find if an airspeed input causes the trailing edge flaps to move. This is the task:
  • Air Data Reference - System Test, AMM TASK 34-21-00-730-802.
NOTE:  Without an airspeed input of more than 60 knots, the FSEU will not sense the undemanded movement fault.
(a)
Move the flap control lever to each detent between the FLAP UP to the FLAP 40 position. Stop at each detent and wait for the flap position indicator needles to stop.
(b)
Move the flap control lever to each detent between the FLAP 40 to the FLAP UP position. Stop at each detent and wait for the flap position indicator needles to stop.
(c)
If the flap position indicator needles do not show the same position as the flap control lever, or if the flaps do not move to all of the positions, then do these steps:
1)
Remove the airspeed simulation.
2)
Remove hydraulic power from system B.
3)
Do the Fault Isolation Procedure below.
(d)
If the flap position indicator needles do show the same position as the flap control lever and you can move the flaps to all of the positons, then continue.
(4)
Do this task:
  • FSEU Display and Existing Faults Test, AMM TASK 27-51-00-740-801.
(a)
Look on the FSEU display or the OMF for related maintenance messages.
(b)
If the maintenance message shows, then do these steps:
1)
Remove the airspeed simulation.
2)
Remove hydraulic power from system B.
3)
Do the Fault Isolation Procedure below.
(c)
If the maintenance message does not show, then there was an intermittent fault.
(d)
Remove the airspeed simulation.
(e)
Remove hydraulic power from system B.
