Maintenance Message 73-43425 - Fault Isolation
ADIRU-L AND ADIRU-R TOTAL PRESSURE SIGNALS DO NOT AGREE
Detected by: ENGINE-2 EEC
A.
Description
(1)
The Total Pressure labels (L242) from ADIRU1 and ADIRU2 are valid but the two sources differ by more than 0.05 Mach with Mach No. greater than 0.3.
B.
Initial Evaluation
(1)
Set the EEC MAINT ENG 2 POWER switch to TEST and wait a minimum of one minute. This is the task:
  • EEC Maintenance Power Selection, AMM TASK G73-21-00-800-801-G00.
(2)
If the OMF shows ACTIVE for the maintenance message, then do these steps:
(a)
Set the EEC MAINT ENG 2 POWER switch to NORM.
(b)
Do the Fault Isolation Procedure below.
(3)
If the OMF shows NOT ACTIVE (or if the message does not show), then there was an intermittent fault.
(a)
Set the EEC MAINT ENG 2 POWER switch to NORM.
C.
Fault Isolation Procedure
(1)
Look in OMF Existing Faults, 31 Indicating Systems for maintenance messages related to these LRUs:
(a)
List of LRUs
1)
Display processing computer 1, M3069
2)
Display processing computer 2, M3070
(b)
If you find any related maintenance messages, then do these steps:
1)
Do the fault isolation task for each related maintenance message.
2)
Set the EEC MAINT ENG 2 POWER switch to TEST and wait a minimum of one minute.
3)
If the OMF shows NOT ACTIVE for the maintenance message (or if the message does not show), then you corrected the fault.
a)
Set the EEC MAINT ENG 2 POWER switch to NORM.
(c)
If you do not find related maintenance messages, then continue.
