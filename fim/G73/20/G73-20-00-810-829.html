Maintenance Message 73-43645 - Fault Isolation
CHANNEL-A AND CHANNEL-B ANALOG ENGINE START LEVER SIGNALS DO NOT AGREE
Detected by: ENGINE-2 EEC
A.
Description
(1)
The start lever hard-wired signal on channel A is not the same state as on channel B.
B.
Initial Evaluation
(1)
Set the EEC MAINT ENG 2 POWER switch to TEST and wait a minimum of one minute. This is the task:
  • EEC Maintenance Power Selection, AMM TASK G73-21-00-800-801-G00.
(2)
If the OMF shows ACTIVE for the maintenance message, then do these steps:
(a)
Set the EEC MAINT ENG 2 POWER switch to NORM.
(b)
Do the Fault Isolation Procedure below.
(3)
If the OMF shows NOT ACTIVE (or if the message does not show), then there was an intermittent fault.
(a)
Set the EEC MAINT ENG 2 POWER switch to NORM.
C.
Fault Isolation Procedure
(1)
Replace the start lever channel A relay (engine 2), R568.
(a)
Set the EEC MAINT ENG 2 POWER switch to TEST and wait a minimum of one minute.
(b)
If the OMF shows NOT ACTIVE for the maintenance message (or if the message does not show), then you corrected the fault.
1)
Set the EEC MAINT ENG 2 POWER switch to NORM.
(c)
If the OMF shows ACTIVE for the maintenance message, then continue.
(d)
Set the EEC MAINT ENG 2 POWER switch to NORM.
(2)
Replace the start lever channel B relay (engine 2), R567.
(a)
Set the EEC MAINT ENG 2 POWER switch to TEST and wait a minimum of one minute.
(b)
If the OMF shows NOT ACTIVE for the maintenance message (or if the message does not show), then you corrected the fault.
1)
Set the EEC MAINT ENG 2 POWER switch to NORM.
(c)
If the OMF shows ACTIVE for the maintenance message, then continue.
(d)
Set the EEC MAINT ENG 2 POWER switch to NORM.
(3)
Do this check of the continuity through the engine 2 start lever (control stand) (WDM 76-21-21):
(a)
Disconnect connector D11290 from the engine 2 start lever (control stand), S1222.
(b)
For each switch position below, set the switch to the specified position and do a check for continuity between the specified pins on the switch:
1)
Switch position Switch S1 to CUTOFF, make sure there is continuity between pin 4 and pin 15.
2)
Switch position Switch S1 to IDLE, make sure there is continuity between pin 5 and pin 15.
(c)
If there was a problem with the continuity, then do these steps:
1)
Replace the engine 2 start lever (control stand), S1222. These are the tasks:
  • Start Lever Removal, AMM TASK G76-11-02-010-801-G00,
  • Start Lever Installation, AMM TASK G76-11-02-420-801-G00.
2)
Re-connect connector D11290 to the engine 2 start lever (control stand), S1222.
3)
Set the EEC MAINT ENG 2 POWER switch to TEST and wait a minimum of one minute.
4)
If the OMF shows NOT ACTIVE for the maintenance message (or if the message does not show), then you corrected the fault.
a)
Set the EEC MAINT ENG 2 POWER switch to NORM.
(d)
If there was not a problem with the continuity, then continue.
(e)
Re-connect connector D11290 to the engine 2 start lever (control stand), S1222.
(4)
Do this check of the continuity through the engine 2 start lever (control stand) (WDM 76-21-21):
(a)
Disconnect connector D11292 from the engine 2 start lever (control stand), S1222.
(b)
For each switch position below, set the switch to the specified position and do a check for continuity between the specified pins on the switch:
