ALT DISAGREE Shows On PFD (Captains's) - Fault Isolation
A.
Description
(1)
This task is for this Non-Message FDE:
(a)
Flight Deck Effect CAPT ALT DISAGREE
(2)
Altitude Disagree annunciation is displayed on the Captain's PFD.
(3)
The ALT DISAGREE message will show when the difference between the Captain's displayed barometric altitude and the First Officer's displayed barometric altitude is more than 200 feet for more than five continuous seconds.
(4)
ADIRU air data parameters can be impacted if the Barometric settings on the EFIS control panels were not set to the same values within 5 seconds of each other.
(5)
If all three flight deck effects, AOA DISAGREE, ALT DISAGREE, and IAS DISAGREE show, then do the FIM task for AOA DISAGREE first.
B.
Fault Isolation Procedure
(1)
Make sure that the Barometric setting on the captain's and the first officer's EFIS control panels are the same.
(2)
Look in OMF Existing Faults for this related maintenance message: 31‑03140.
(a)
If you find the related maintenance message, then do these steps:
1)
Do the fault isolation task for maintenance message 31‑03140 (AOA DISAGREE SHOWS ON CAPT OR F/O PFD).
2)
If the observed fault symptom does not occur on the subsequent flight, then you corrected the fault.
(b)
If you do not find the related maintenance message, then continue.
(3)
Look in OMF Existing Faults, 34 Air Data Inertial Reference System for maintenance messages related to these LRUs:
(a)
List of LRUs
1)
Lower left pitot probe, A23
2)
Upper right pitot probe, A26
3)
Total air temperature sensor, M171
4)
Left angle of attack sensor, T433
5)
Right angle of attack sensor, T437
6)
Left static air data module, M1751
7)
Right static air data module, M1754
8)
Left air data/inertial reference unit, M1749
9)
Right air data/inertial reference unit, M1752
10)
Left pitot air data module, M1750
11)
Right pitot air data module, M1753
(b)
If you find any related maintenance messages, then do these steps:
1)
Do the fault isolation task for each related maintenance message.
2)
If the observed fault symptom does not occur on the subsequent flight, then you corrected the fault.
(c)
If you do not find related maintenance messages, then continue.
(4)
Do this task:
  • Pitot Static System - Flushing, AMM TASK 34-11-00-170-802.
NOTE:  The flushing task includes a leak check and sensor inspection. This applies to the left and right primary systems.
(a)
If you find unwanted moisture, contamination, or other problems during the task, then do these steps:
1)
Repair the problems that you find.
2)
If the observed fault symptom does not occur on the subsequent flight, then you corrected the fault.
(b)
If you do not find unwanted moisture, contamination, or other problems during the task, then continue.
(5)
Do a detailed visual inspection of the pitot and static system hoses.
(a)
Look for kinks, sharp turns, and something pressing against a line. Also look for loose connections at B-nuts and check all quick disconnects.
(b)
If you find a problem during the inspection, then do these steps:
1)
Repair or replace the bad components.
2)
If the observed fault symptom does not occur on the subsequent flight, then you corrected the fault.
(c)
If you do not find a problem during the inspection, then continue.

(b)
If you do not find a problem during the test, then continue.
(8)

(a)

(b)

1)
Pin 41 to ground, specified resistance = 40 to 56 ohms at an ambient temperature of 68 degrees F ( 20 degrees C). Note: The specified resistance is temperature dependent.
(c)
If the resistance is not in the specified range, then do these steps:
1)
Replace the lower left pitot probe, A23. These are the tasks:
  • Pitot Probe - Removal, AMM TASK 34-11-01-000-801,
  • Pitot Probe - Installation, AMM TASK 34-11-01-400-801.

(d)
If the resistance is in the specified range, then continue.
