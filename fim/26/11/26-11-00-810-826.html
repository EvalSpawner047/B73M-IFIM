Maintenance Message 26-00130 - Fault Isolation
ENGINE-1 LOOP A HAS A CORE LEFT DETECTOR SIGNAL ERROR
Detected by: ENGINE FIRE DETECTION CONTROL UNIT (EFDCU)
A.
Description
(1)
This task is for this maintenance message:
(a)
ENGINE-1 LOOP A HAS A CORE LEFT DETECTOR SIGNAL ERROR
(2)
This fault occurs when the fire detection control module, M279 detects a fault with an engine fire detector element.
B.
Initial Evaluation
(1)
For the engines/APU fire control panel, P8-1, do the "FIRE/OVHT Test" part of this task:
  • Engine Fire Detection - Operational Test, AMM TASK 26-11-00-710-801.
(2)
If the OMF shows ACTIVE for the maintenance message, then do the Fault Isolation Procedure below.
(3)
If the OMF shows NOT ACTIVE for the maintenance message, then there was an intermittent fault.
C.
Fault Isolation Procedure
(1)
Do this check of the resistance of the engine/APU fire detection module through its wiring:
(a)
Remove the engine/APU fire detection module, M279. This is the task:
  • Engine and APU Fire Detection Module Removal, AMM TASK 26-10-01-000-801.
(b)
Measure the resistance between these pairs of pins at connector D1002 (WDM 26-11-11):
1)
Pin 25 to Ground, specified resistance 841 to 921 ohms.
(c)
If the resistance is in the specified range, then do these steps:
1)
Replace the engine/APU fire detection module, M279. These are the tasks:
  • Engine and APU Fire Detection Module Removal, AMM TASK 26-10-01-000-801,
  • Engine and APU Fire Detection Module Installation, AMM TASK 26-10-01-400-801.
2)
Do the AMM test of the engines/APU fire control panel that you did at the start of this task.
3)
If the OMF shows NOT ACTIVE for the maintenance message (or if the message does not show), then you corrected the fault.
(d)
If the resistance is not in the specified range, then continue.
(2)
Do this check of the wiring:
(a)
Disconnect the wires from the engine fan right fire detector loop A (engine 1), M3042.
(b)
Do a wiring check between these pins of connector D1002 at the E2-2 rack and these wire terminals at the engine fan right fire detector loop A (engine 1) (WDM 26-11-11):
D1002M3042_1A
pin 25--------------------term C
pin GD3838-ST--------------------term G
(c)
If you find a problem with the wiring, then do these steps:
1)
Repair the wiring.
2)
Re-install the engine/APU fire detection module, M279. This is the task:
  • Engine and APU Fire Detection Module Installation, AMM TASK 26-10-01-400-801.
3)
Re-connect the wires to the engine fan right fire detector loop A (engine 1), M3042.
4)
Do the AMM test of the engines/APU fire control panel that you did at the start of this task.
5)
If the OMF shows NOT ACTIVE for the maintenance message (or if the message does not show), then you corrected the fault.
(d)
If you do not find a problem with the wiring, then continue.
(e)
Re-install the engine/APU fire detection module, M279. This is the task:
  • Engine and APU Fire Detection Module Installation, AMM TASK 26-10-01-400-801.
