Maintenance Message 77-41601 - Fault Isolation
EXHAUST GAS TEMPERATURE (EGT) PROBE 1 SIGNAL IS OUT OF RANGE
Detected by: ENGINE-1 EEC CHANNEL-A
A.
Description
(1)
EGT Probe 1 thermocouple signal exceeds the upper limit of 1262.0 degrees C, or is less than the lower limit of -77 degrees C or the EEC input circuitry is failed, or the thermocouple cold junction temperature is invalid. The fault report is set on channel A.
B.
Initial Evaluation
(1)
If the OMF shows ACTIVE for the maintenance message, then do the Fault Isolation Procedure below.
(2)
If the OMF shows NOT ACTIVE or LATCHED for the maintenance message (or if the message does not show), then do these steps:
(a)
Do this task for engine 1:
  • Test No. 32 - Engine Idle System Test, AMM TASK G71-00-00-700-808-G00.
(b)
If the maintenance message shows on the ground test display, then do the Fault Isolation Procedure below.
(c)
If the maintenance message does not show on the ground test display, then there was an intermittent fault.
C.
Fault Isolation Procedure
 BE CAREFUL WHEN YOU DO WORK ON THE ENGINE PARTS AFTER THE ENGINE IS STOPPED. THE ENGINE PARTS CAN STAY HOT FOR ALMOST ONE HOUR. DO NOT TOUCH HOT PARTS WITHOUT APPLICABLE GLOVES. HOT PARTS CAN CAUSE INJURIES TO PERSONNEL.
(1)
Do a detailed visual inspection of the EGT probe 1 (engine 1), 69700 and its attachment fasteners, gasket seal and the electrical terminal connections to the EGT harness leads. This is the task:
  • Engine Temperature Sensing System Inspection, AMM TASK G77-21-00-210-801-G00.
(a)
Look for missing or loose parts, interference, wear, or damage.
(b)
If you find a problem during the inspection, then do these steps:
1)
Repair or replace the bad components.
2)
Do this task for engine 1:
  • Test No. 32 - Engine Idle System Test, AMM TASK G71-00-00-700-808-G00.
3)
If the maintenance message does not show on the ground test display, then you corrected the fault.
(c)
If you do not find a problem during the inspection, then continue.
(2)
Do a detailed visual inspection of the electronic engine control A (engine 1), 65H00 and its attachment fasteners, wire harness, and connector. This is the task:
  • Fuel Control System Inspection, AMM TASK G73-21-00-200-801-G00.
(a)
Look for missing or loose parts, interference, wear, or damage.
(b)
If you find a problem during the inspection, then do these steps:
1)
Repair or replace the bad components.
2)
Do this task for engine 1:
  • Test No. 32 - Engine Idle System Test, AMM TASK G71-00-00-700-808-G00.
3)
If the maintenance message does not show on the ground test display, then you corrected the fault.
(c)
If you do not find a problem during the inspection, then continue.
(3)
Do this check of the resistance of the EGT probe 1 (engine 1):
(a)
Disconnect connector DP88A from the engine core temperature transition support bracket (engine 1).
(b)
Measure the resistance between these pins of connector DJ88A at the engine core temperature transition support bracket (engine 1) (WDM 77-21-11):
1)
Pin 1 to pin 2, specified resistance 5.2 to 8.2 ohms.
2)
Pin 1 to ground, specified resistance greater than 10 Megohms.
3)
Pin 2 to ground, specified resistance greater than 10 Megohms.
(c)
If the resistance is not in the specified range, then do these steps:
1)
Replace the EGT probe 1 (engine 1), 69700. These are the tasks:
  • Exhaust Gas Temperature Sensors Removal, AMM TASK G77-21-01-000-801-G00,
  • Exhaust Gas Temperature Sensors Installation, AMM TASK G77-21-01-400-801-G00.
2)
Do this task for engine 1:
  • Test No. 32 - Engine Idle System Test, AMM TASK G71-00-00-700-808-G00.
3)
If the maintenance message does not show on the ground test display, then you corrected the fault.
(d)
If the resistance is in the specified range, then continue.
(4)
Do this check of the wiring:
(a)
Disconnect the wires from the EGT probe 1 (engine 1), 69700.
(b)
Do a wiring check between these wire terminals at the EGT probe 1 (engine 1) and these pins of connector DJ88A at the engine core temperature transition support bracket (engine 1) (WDM 77-21-11):
69700_11DJ88A
term KP(CR)--------------------pin 1
term KN(AL)--------------------pin 2
(c)
If you find a problem with the wiring, then do these steps:
1)
Repair or replace the upper EGT harness 1 (engine 1), 6500A. These are the tasks:
  • Exhaust Gas Temperature Sensor Harness 1 Removal, AMM TASK G77-21-04-000-801-G00,
  • Exhaust Gas Temperature Sensor Harness 1 Installation, AMM TASK G77-21-04-400-801-G00.
2)
Re-connect the wires to the EGT probe 1 (engine 1), 69700.
3)
Re-connect connector DP88A to the engine core temperature transition support bracket (engine 1).
4)
Do this task for engine 1:
  • Test No. 32 - Engine Idle System Test, AMM TASK G71-00-00-700-808-G00.
5)
If the maintenance message does not show on the ground test display, then you corrected the fault.
(d)
If you do not find a problem with the wiring, then continue.
(e)
Re-connect the wires to the EGT probe 1 (engine 1), 69700.
(5)
Do this check of the wiring:
(a)
Disconnect connector DP8A from the electronic engine control A (engine 1), 65H00.
(b)
Do a wiring check between these pins of connector DP88A at the engine core temperature transition support bracket (engine 1) and these pins of connector DP8A at the electronic engine control A (engine 1) (WDM 77-21-11):
DP88ADP8A
pin 1--------------------pin W
pin 2--------------------pin -r
(c)
If you find a problem with the wiring, then do these steps:
1)
Repair or replace the HJ8A harness (engine 1), 65007. These are the tasks:
  • Electronic Engine Control (EEC) Electrical Harness (HJ8A) Removal, AMM TASK G73-22-01-000-808-G00,
  • Electronic Engine Control (EEC) Electrical Harness (HJ8A) Installation, AMM TASK G73-22-01-400-808-G00.
2)
Re-connect connector DP88A to the engine core temperature transition support bracket (engine 1).
3)
Re-connect connector DP8A to the electronic engine control A (engine 1), 65H00.
4)
Do this task for engine 1:
  • Test No. 32 - Engine Idle System Test, AMM TASK G71-00-00-700-808-G00.
5)
If the maintenance message does not show on the ground test display, then you corrected the fault.
(d)
If you do not find a problem with the wiring, then continue.
(e)
Re-connect connector DP88A to the engine core temperature transition support bracket (engine 1).
(6)
Replace the electronic engine control A (engine 1), 65H00. These are the tasks:
  • Electronic Engine Control (EEC) Channel A Removal, AMM TASK G73-21-05-000-801-G00,
  • Electronic Engine Control (EEC) Channel A Installation, AMM TASK G73-21-05-400-801-G00.
(a)
Do this task for engine 1:
  • Test No. 32 - Engine Idle System Test, AMM TASK G71-00-00-700-808-G00.
(b)
If the maintenance message does not show on the ground test display, then you corrected the fault.
